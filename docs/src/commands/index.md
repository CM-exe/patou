# Commands

Patou has three subcommands:

- [`patou init`](./init.md) — scaffold `.patou/` in a Git repository.
- [`patou install`](./install.md) — activate hooks for one clone.
- [`patou check`](./check.md) — validate a commit message against the
  configured rules.

Run `patou --help` or `patou <command> --help` for the exact flags.
